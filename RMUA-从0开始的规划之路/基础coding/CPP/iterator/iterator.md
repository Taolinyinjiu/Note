# 迭代器

迭代器是一种工具，它是C++标准模板库STL的核心概念之一，允许程序员通过统一的方式来访问容器中的元素，而不需要关心容器的具体实现细节。

迭代器是一个对象，它提供了一种方法来遍历容器中的元素，迭代器可以被视为指向容器内部元素的指针，但是它比指针更加强大和灵活，迭代器可以用于访问，修改容器中的元素，并且可以与STL算法一起使用。

## 迭代器的主要分类
- 输入迭代器：只进行一次读取操作，不能进行写入操作
- 输出迭代器：只进行一次写入操作，不能进行读取操作
- 正向迭代器：可以进行写入和读取操作，并且可以向前移动
- 双向迭代器：在正向迭代器的功能上，还可以向后移动
- 随机访问迭代器：在双向迭代器的功能上，还可以进行随机访问，比如通过下标访问元素

## 语法
```cpp
#include <iterator>

// 使用迭代器遍历容器
for (ContainerType::iterator it = container.begin(); it != container.end(); ++it) {
    // 访问元素 *it
}

```
