TP (True Positive)：一个正确的检测，检测的IOU ≥ threshold。即预测的边界框(bounding box)中分类正确且边界框坐标正确的数量。在实际预测中，经常会出现多个预测框与同一个gt的IOU都大于阈值，这时通常只将这些预测框中score最大的算作TP，其它算作FP。

FP (False Positive)：一个错误的检测，检测的IOU < threshold。即预测的边界框中分类错误或者边界框坐标不达标的数量，即预测出的所有边界框中除去预测正确的边界框，剩下的边界框的数量。

FN (False Negative)：一个没有被检测出来的ground truth。所有没有预测到的边界框的数量，即正确的边界框(ground truth)中除去被预测正确的边界框，剩下的边界框的数量。

Precision (准确率 / 精确率)：「Precision is the ability of a model to identify only the relevant objects」，准确率是模型只找到相关目标的能力，等于TP/(TP+FP)。即模型给出的所有预测结果中命中真实目标的比例。对于某个类别A，我们先计算每张图片中A类别TP和FP的数量并进行累加，即可得到类别A在整个数据集中TP和FP的数量，计算TP/(TP+FP)即可得到类别A的Precision (计算Precision的时候只需要用到TP和FP)，但是会发现Precision的数值是受模型预测出的边界框的数量(上述计算式的分母部分)影响的，如果我们控制模型输出预测框的数量，就可以得到不同的Precision，所以我们可以设置不同的score阈值，最终得到不同数量的TP和FP。

Recall (召回率)：「Recall is the ability of a model to find all the relevant cases (all ground truth bounding boxes)」，召回率是模型找到所有相关目标的能力，等于TP/(TP+FN)。即模型给出的预测结果最多能覆盖多少真实目标。对于某个类别A，按上述方法进行累加TP的数量，计算TP/(n_gt)即可得到Recall，其中n_gt表示类别A在所有图片中gt的数量之和。同理，如果控制模型输出的预测框的数量，就会改变TP的数量，也就会改变Recall的值。

score、confidence：每个预测边界框的分数/置信度，不同论文中的表达方式不同。即你的模型除了需要给出每个预测边界框的分类结果和边界坐标，还要给出这个边界框包含目标的可能性，score/confidence高代表模型认为其包含目标的可能性大，或者说模型优先选择score/confidence高的边界框。

Precision x Recall curve (PR曲线)：所有precision-recall点相连形成的曲线(一般会为每个类别的预测框建立各自的PR曲线)。至于为什么同一个recall值下会有多个precision值，可以看之后部分的解释。想要得到PR曲线，可以通过改变score的阈值来控制模型输出的预测框数量，从而得到不同的TP、FP、FN。不过在实际操作中，并不需要手动来设置score的阈值，因为每个预测框都有一个score，我们只需要将其按从小到大进行排序，然后每次选择最后一个score作为阈值即可，这样如果类别A在所有图片中的预测框数量之和有100个，就可以计算100组类别A的Precision-Recall值。

AP (average Precision)：平均精度，在不同recall下的最高precision的均值(一般会对各类别分别计算各自的AP)

Recall-Confidence Curve (召回率-置信度曲线) 是一种在机器学习，特别是目标检测、信息检索等领域中用于评估模型性能的曲线。它展示了模型的召回率（Recall）如何随着置信度阈值（Confidence Threshold）的变化而变化。

召回率，也就是Recall 它的计算方式：Recall  = TP/(TP+FN)，上面有提到这都是什么

置信度 (Confidence)：模型对某个预测结果的“确信”程度。在目标检测中，通常是模型预测一个边界框包含某个目标时，给出的一个概率值。在分类任务中，可以是模型预测某个样本属于某个类别的概率。

置信度阈值 (Confidence Threshold)：我们设定一个阈值，只有当模型的置信度超过这个阈值时，我们才认为这个预测是有效的。例如，在目标检测中，如果模型预测一个物体存在的置信度为0.7，而我们设定的阈值为0.6，那么这个预测就会被接受；如果阈值为0.8，这个预测就会被拒绝。

### Recall-Confidence Curve 的构成和意义

Recall-Confidence Curve 的绘制方式是：

1. 将模型的所有预测结果按照置信度从高到低排序。
2. 从最高的置信度开始，逐渐降低置信度阈值。
3. 对于每一个置信度阈值，计算当前的召回率。
4. 以置信度为横轴，召回率为纵轴，绘制曲线。


这条曲线的意义在于：

展现召回率与置信度的权衡关系：

当置信度阈值设置得很高时（例如，只接受置信度非常高的预测），模型的召回率通常会比较低。因为很多真实的正样本可能模型预测的置信度没有那么高，会被过滤掉。
随着置信度阈值的降低，模型会接受更多预测结果，其中会包含更多的真实正样本（TP），从而提高召回率。但同时，也可能引入更多的假阳性（False Positives），尽管 Recall-Confidence Curve 主要关注召回率。
帮助选择最佳置信度阈值：通过观察曲线，我们可以找到一个平衡点，即在保证可接受的召回率的同时，尽可能地提高模型对预测结果的置信度。例如，如果曲线在某个置信度范围内召回率急剧上升，那么这个范围可能是一个需要关注的阈值区间。

评估模型在不同置信度下的表现：Recall-Confidence Curve 提供了一种直观的方式，让我们了解模型在不同“严格”程度下的表现。


## F1-Confidence Curve

F1-Confidence Curve（F1-置信度曲线）与 Recall-Confidence Curve 类似，也是机器学习模型性能评估中的重要工具，尤其是在分类或检测任务中。它展示了模型的 F1-score 如何随着 置信度阈值 的变化而变化。

### F1-score (F1 分数)

F1-score 是精确率（Precision）和召回率（Recall）的调和平均值。它旨在综合考虑模型的精确率和召回率，尤其在类别不平衡的数据集中，F1-score 往往比单一的准确率（Accuracy）更能反映模型的真实性能。

F1-score 的计算公式为 F1 = 2 x (Precision x Recall) / (Precision + Recall)

F1-score 的取值范围是 0 到 1，其中1 表示完美的精确率和召回率，0 表示最差的性能。当精确率和召回率都较高时，F1-score 才会高。如果其中一个非常低，F1-score 也会随之降低。

### F1-Confidence Curve 的构成和意义

F1-Confidence Curve 的绘制方式与 Recall-Confidence Curve 类似：

1. 将模型的所有预测结果（通常包含置信度）按照置信度从高到低排序。
2. 从最高的置信度开始，逐渐降低置信度阈值。
3. 对于每一个置信度阈值，根据当前阈值下被接受的预测结果，计算相应的精确率、召回率，进而计算出 F1-score。
4. 以置信度为横轴，F1-score 为纵轴，绘制曲线。

### 这条曲线的意义在于：

综合评估模型性能与置信度的关系：
F1-Confidence Curve 直接展示了在不同置信度要求下，模型整体性能（精确率和召回率的平衡）如何变化。

帮助选择最佳置信度阈值：
在许多实际应用中，我们不仅希望模型能够尽可能多地召回正样本，也希望召回的样本是准确的。F1-score 提供了一个平衡这两者考量的指标。通过 F1-Confidence Curve，我们可以找到 F1-score 达到峰值或处于较高水平的置信度阈值。这个阈值通常被认为是模型在此任务上的“最佳”工作点，因为它在该点上实现了精确率和召回率的较好平衡。

对比不同模型的稳健性：
通过比较不同模型的 F1-Confidence Curve，可以判断哪个模型在不同置信度下表现更稳定，或者哪个模型在某个特定的置信度区间内性能更优。

理解模型在不同“严格”程度下的平衡能力：
当置信度阈值很高时，模型会非常“严格”，只接受它最有信心的预测。这通常会导致高精确率（因为只接受了“很有把握”的预测），但可能召回率较低（因为很多真实正样本的置信度可能没那么高而被滤掉了）。此时 F1-score 的表现取决于精确率和召回率的权衡。
随着置信度阈值降低，模型会变得“宽松”，接受更多预测。召回率通常会上升，但精确率可能会下降（因为引入了更多错误的预测）。F1-score 会在这个过程中先上升后下降，因为存在一个最优的平衡点。

### 如何解读 F1-Confidence Curve：
曲线的峰值：F1-Confidence Curve 的最高点对应的置信度阈值，是该模型在给定数据集上 F1-score 最高的阈值。这通常是我们寻找的最佳操作点。

曲线的形状：
理想情况下，我们希望曲线能在较高的置信度下也能保持较高的 F1-score，并且 F1-score 的峰值尽可能接近 1。
如果曲线的 F1-score 峰值很低，说明模型整体性能不佳。
如果峰值出现在非常低的置信度，意味着模型需要在非常“宽松”的条件下才能达到较好的平衡，这可能说明模型的置信度预测不够可靠。
F1-score 的变化趋势：通常，随着置信度阈值的降低，F1-score 会先上升，达到一个峰值，然后下降。这是因为刚开始降低阈值时，召回率的增加带来的收益大于精确率的下降，F1-score 上升；但当阈值过低时，引入了过多的假阳性（FP），导致精确率大幅下降，F1-score 也随之下降。


## Result
在训练完成后，会输出result.png图像，其中有十个字图，分为三大类，分别是训练损失，验证损失，评估指标

### 训练损失 (Train Losses)

这三张图显示了模型在训练集上学习过程中的损失变化。损失值越低越好，表明模型在学习任务上表现越好。

train/box_loss (BBox Loss / 定位损失)
含义: 衡量模型预测的边界框（bounding box）与真实标注边界框之间的差异。它反映了模型预测物体位置和大小的准确性。
解读: 曲线通常会随着训练轮次（epoch）的增加而逐渐下降。如果下降平稳且最终值较低，说明模型在定位物体方面学习得很好。如果波动较大或下降不明显，可能需要调整学习率、优化器或模型结构。

train/cls_loss (Classification Loss / 分类损失)
含义: 衡量模型预测的物体类别与真实类别之间的差异。它反映了模型识别物体种类的准确性。
解读: 同样会随着训练轮次增加而下降。较低的分类损失意味着模型能够准确地判断边界框内物体的类别。

train/dfl_loss (DFL Loss / Distribution Focal Loss)
含义: 这是 YOLOv5（以及后续版本）中引入的一种损失函数，用于优化边界框回归的置信度。它鼓励模型将边界框的坐标分布预测得更“尖锐”和准确，从而提高定位精度。
解读: 同样是下降趋势，反映了模型在边界框回归的精确度上有所提升。

### 验证损失 (Validation Losses)

这三张图显示了模型在验证集（未参与训练的数据）上的损失变化。验证损失是评估模型泛化能力的关键。

val/box_loss (Validation BBox Loss)
含义: 模型在验证集上的边界框定位损失。
解读: 同样是下降趋势。如果 val/box_loss 持续下降，但 train/box_loss 已经很低并趋于平稳，可能表明模型仍然有改进空间。如果 val/box_loss 在某个点开始上升，而 train/box_loss 持续下降，这可能是过拟合的迹象，即模型在训练集上表现很好，但在新数据上表现变差。图中的 val/box_loss 波动较大，可能需要更长的训练时间，或者在后续批次中增加验证集的采样频率以获得更平滑的曲线。


val/cls_loss (Validation Classification Loss)
含义: 模型在验证集上的分类损失。
解读: 与 val/box_loss 类似，用于评估模型在未见过数据上的分类能力。同样需要关注是否出现过拟合。

val/dfl_loss (Validation DFL Loss)
含义: 模型在验证集上的 DFL 损失。
解读: 与训练集上的 DFL 损失对应，评估模型在泛化到新数据时，边界框回归的精确度。图中波动也较大。


### 评估指标 (Metrics)

这三张图展示了模型在验证集上的评估指标，这些指标直接反映了模型的检测性能。

metrics/precision(B) (Precision)
含义: 精确率。衡量模型预测为正样本（这里是检测到物体）的框中，有多少是真正的正样本。
解读: 曲线通常会上升并趋于稳定。高的精确率意味着模型误报（将背景误判为物体，或将一个物体误判为另一个物体）较少。图中，精确率很快达到并维持在1.0附近，这可能表明：
模型在区分正负样本方面表现非常好。
潜在问题: 可能是因为数据集中的正样本数量非常少，或者模型只检测到了非常明显的、少量的物体，导致分母（TP+FP）中的FP非常少，从而使得精确率虚高。需要结合召回率和mAP来综合判断。

metrics/recall(B) (Recall)
含义: 召回率。衡量所有真实正样本中，有多少被模型成功检测到。
解读: 曲线通常会上升并趋于稳定。高的召回率意味着模型漏报（未能检测到真实物体）较少。图中，召回率也很快达到并维持在1.0附近。与精确率类似，这可能意味着：
模型在找回所有正样本方面表现非常好。
潜在问题: 如果精确率和召回率都非常高且达到1.0，这在真实世界复杂数据集上是极其罕见的。这可能暗示数据集过于简单，或者存在数据泄漏（验证集和训练集有重复），或者评估方法有误。需要仔细检查数据集和评估流程。

metrics/mAP50(B) (Mean Average Precision at IoU=0.50)
含义: mAP@0.50。这是目标检测领域最常用的评估指标之一。它计算了在交并比（IoU）阈值为 0.50 的情况下，所有类别的平均精确率（AP），然后取所有类别的平均值。
IoU (Intersection over Union): 衡量预测框与真实框重叠程度的指标。
解读: 曲线通常会上升并趋于稳定。越高的 mAP50 越好，表明模型在 IoU=0.50 的标准下，能够很好地定位和分类物体。图中，mAP50 很快达到1.0并维持。这与精确率和召回率接近1.0的情况类似，强烈暗示数据集可能存在问题，或者说模型在当前数据集上表现过于完美，以至于难以评估其在更复杂场景下的真实性能。

metrics/mAP50-95(B) (Mean Average Precision at IoU=0.50:0.95)
含义: mAP@0.50:0.95。这是更严格的 mAP 指标。它计算了在不同 IoU 阈值（从 0.50 到 0.95，步长 0.05）下的平均精确率，然后取这些 AP 值的平均值。
解读: 通常这个值会低于 mAP50，因为它对定位的准确性要求更高。高的 mAP50-95 意味着模型不仅能找到物体，还能非常精确地定位它们。图中，mAP50-95 也非常高，达到0.8以上并趋于平稳。这进一步证实了模型在当前数据集上的优异表现
