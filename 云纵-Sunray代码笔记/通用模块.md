整体来看，除去ros环境下编译产生的中间件以及各类辅助文件，Sunray的核心部分可以拆解为三大块
1. 外部算法: 集中在External_Module文件夹下 
   1. ego-planner-swarm : 基于ego-planner的集群导航版本，单机同样适用
   2. FUEL : 未知环境下无人机自主探索框架
   3. geographic-lib : 高精度地理计算库，通过GPS进行定位时依赖该库解算坐标系
   4. sunray_detection : 内部为yolo v7算法，用于目标识别项目中
   5. turn_on_wheeltec_robot : 轮趣无人机ros驱动的底层功能包，用于uav跟随小车项目
   6. vrpn_client_ros: vrpn主要用于动作捕获(动捕)项目中，uav的位姿通过外部视觉捕获并给到ros话题
2. 自研内部算法: 集中在General_Module文件夹下
   1. sunray_common: Sunray系列通用头文件，以及各种自定义的ros消息格式
   2. sunray_gimbal: Sunray系列中有关云台控制相关功能实现
   3. sunray_media: Sunray系列有关视频推流等相关功能的实现
   4. sunray_planner_utils: Sunray系列中与规划、SLAM等相关项目有关的启动文件、脚本，以及相关的工具
   5. sunray_tutorial: Sunray系列中与无人机控制接口有关的教程包
   6. sunray_uav_control: Sunray系列中无人机控制接口包
   7. sunray_ugv_control：在与无人车有关的项目中，无人车的运动控制包
3. 通信组件相关：集中在Comunication_Module文件夹下并且只有sunray_communication_bridge一个软件包
   1. 通信组件用于无人机与自研地面站之间进行通信
4. 启动脚本
   1. 实机启动脚本放置在文件夹 `scripts_exp`下
      1. Astar_run_exp.sh ： A* 算法在实机上的部署
      2. *_viobot.sh : 关于配置了viobot的无人机相关项目启动脚本
      3. *_mid360.sh : 配置了mid360激光雷达的无人机相关项目，主要有两个，分别是基础控制control和ego导航
   2. 仿真项目启动脚本放置在文件夹 `scripts_sim`下
   3. 集群无人机项目的启动脚本放置在文件夹`scripts_swarm`下
5. 仿真器: 主要集中在Simulation文件夹下
   1. 2025_uav_competition_demo : 2025年某个比赛的仿真环境
   2. future_2025_score:2025年某个比赛的仿真环境
   3. gazebo_plugin: gazebo仿真器中用到的相关插件
   4. simulator_utils: 仿真器自身用到的相关插件
   5. sunray_simulator: 有关仿真器的自身实现
   6. sysu_competition: 一些测试文件
6. 集群编队: 主要集中在sunray_formation文件夹下
   1. formation_control : 集群实机相关实现
   2. formation_sim : 集群仿真相关实现
   3. sunray_orca : 集群规划避障算法
7. 编译相关
   1. buildscripts : 编译过程中使用到的各种脚本文件
   2. build : 编译完成后的相关文件
