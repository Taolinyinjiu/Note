Each participating team must provide at least one (1) but no more than three (3) aerial robot units. Custom-built aerial robots are permitted, provided all equipment meets the following specifications: 
1. Configuration: Quadcopter only (180–350mm wheelbase) 
2.  Battery: ≤27V, with safety-certified
3.  Weight: ≤3.0 kg at takeoff 
4.  Autonomy: No remote control during tasks; onboard sensing only
5.  Safety: Remote kill-switch mandatory
6.  Identification: Each aerial robot must display a clear teamidentifier for referee recognition. 
7.  Positioning Requirements: Only onboard sensors (such as LiDAR, vision, etc.) are allowed for positioning. The use of any external positioning aids (such as motion capture, UWB base stations, or external QR codes) is strictlyprohibited.
   
英译中

每个队伍，必须提供至少一个，至多三个的空中自主无人机，并且需要满足以下要求
1. 仅使用四旋翼，轴距限制在180mm - 350mm
2. 供电电压必须小于等于27V，并且电池需要安全认证
3. 起飞时整机重量小于3kg
4. 在空中执行任务期间，没有远程控制，并且只能使用板载传感器
5. 必须具备远程安全开关
6. 每个空中无人机，机身必须具备明确的团队标识符
7.  仅允许使用机载传感器，如雷达，视觉设备等，禁止使用外部定位设备，如UWB，动捕等
   

为了调试方便，允许使用移动网络和WIFI模块，但是，比赛当天，只有正在比赛的队伍可以使用WIFI进行调试，其余队伍应当关闭，以防止对其通信产生干扰

团队可以由6人组成，并且最多由两名指导老师，团队6人中，最少有一位具有手动飞行经验

注意，在附加题目内容中，可通过空间尺寸为0.6m x 0.35m
