RMUA - 从0开始的规控之路

1. 规控，全称为规划控制。在本次教程中，特指以无人机为载体的，自主机器人三维空间上的规划控制、
2. 规划，指的是通过无人机搭载的传感器，如激光雷达，双目相机，IMU，GPS等，获取外界信息，从而建立 无人机 - 周围障碍物 - 当前位置与目标点位置 的关系，然后生成一条光滑的轨迹
3. 控制，指的是通过动力学与运动学关系，通过对四个电机转速的控制 - 四个电机产生推力 - 影响无人机姿态 - 使无人机跟踪规划模块所规划出来的轨迹 
4. 因此 ，在设计无人机的运动模块时，我们通常将规划器和控制器分开设计。规划器的目标是产生一条，安全，光滑，最优的轨迹。控制器的目标是接收轨迹，并跟踪轨迹。
