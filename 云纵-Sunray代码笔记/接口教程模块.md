# sunray_tutorial

在sunray_tutorial软件包中，节点由cpp进行编写，根据节点功能将源文件放置在三个文件夹中
- advanced sunray的高级控制接口
- uav_basic sunray的基本控制接口
- ugv_basic 阿木系列无人车的ros驱动节点，内部为矩形和圆形轨迹跟踪，并可指定速度


在Sunray系列中，对于uav的basic控制接口一共有以下几种：
- XyzPos ( xyz三方向的位置)
- XyzVelPos ( xyz三方向的速度与位置)
- XyzVel ( xyz三方向的速度)
- xy vel z pos yaw body
- xyz vel yaw body
- Xyz Pos Yaw Body

对于advanced控制接口，其主要由三个不同接口实现的自动降落和一个避障逻辑
- 使用XyzPosYawBody接口实现的自动降落 `auto_land_by_pose`
- 使用XyzVelYawBody接口实现的自动降落 `auto_land`
- 使用XyzVelYawBody接口实现的自动降落 `land_on_a_moving_car`，重点在于实现降落到移动中的小车上
- `simple_obstacle_avoidance` 实现了一个带有避障功能的无人机自主导航功能，使无人机能够在检测到前方障碍物的时候避开障碍物，继续朝目标点飞行

string get_state_name(AvoidanceState state) {
    switch(state) {
        case NAVIGATING_TO_TARGET: return "导航至目标";
        case AVOIDING_OBSTACLE: return "避障中";
        case CLEARING_OBSTACLE: return "清除障碍";
        case TURNING_TO_TARGET: return "转向目标";
        case REACHED_TARGET: return "到达目标";
        default: return "未知状态";
    }
}
